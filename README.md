# 🏎️ SuperSprint

A 2D top-down arcade racing game inspired by the classic *Super Sprint*, built in Python using **PySide6** and **SciPy**, based on the **G2D** library from [fondinfo](https://fondinfo.github.io)

---

## 🛠️ Prerequisites & Installation

Make sure you have Python 3 installed, then install the required dependencies (preferably inside a virtual environment):

```bash
pip install PySide6 scipy
```

## 🚀 How to Run

Start the game by executing the main script from your terminal:

```
python main.py
```
#### ⚠️ Heads-up: The race starts immediately upon launch! Keep your hands on the keyboard so you don't miss the start.

## 🏁 Gameplay & Rules

- 🕹️ ***Objective***: Complete the required number of laps around the circuit following the track direction. Avoid crashing into the arena walls!
- 🛢️ ***Oil Puddles***: Watch out for oil spills on the asphalt—hitting them will make you lose control and slow you down.
- 🔧 ***Wrenches***: Collect wrenches scattered across the track to upgrade your car's top speed and performance.
